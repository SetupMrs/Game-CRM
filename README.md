# 🖥️ Локальна CRM & SRM Система

Це повноцінна веб-додаток (React + Express + Node.js), який розроблений для запуску безпосередньо на вашому власному комп'ютері (PC) та працює повністю автономно.

---

## 💾 Як влаштовано збереження даних на вашому ПК

Ваші дані мають потрійний рівень надійності та зберігаються виключно локально:

1. **Локальний JSON-файл**: Всі ваші завдання, фінансові транзакції, постачальники та картки товарів зберігаються прямо на вашому жорсткому диску у файлі `data/crm_srm_db.json`.
2. **Локальна пам'ять браузера (LocalStorage)**: Веб-версія дублює стан бази даних у вашому браузері. Навіть якщо сервер тимчасово зупинено, ваші дані надійно збережені на ПК.
3. **Ручні резервні копії (Один клік)**:
   * На верхній панелі додано кнопку **«Зберегти на ПК»**, яка миттєво скачує файл резервної копії `.json`.
   * Кнопка **«Завантажити з ПК»** дозволяє у будь-який момент імпортувати вашу збережену базу даних на будь-якому іншому комп'ютері.

---

## 🚀 Інструкція: Як запустити систему локально на своєму комп'ютері

Щоб перенести систему з хмари на свій комп'ютер і використовувати її як персональну програму:

### Крок 1. Скачайте проект на ПК
1. У правому верхньому кутку Google AI Studio натисніть на меню налаштувань (або меню експорту).
2. Оберіть **"Export as ZIP"** (Скачати як ZIP-архів) або експортуйте безпосередньо до свого **GitHub** репозиторію.
3. Розпакуйте завантажений ZIP-архів у будь-яку зручну папку на вашому комп'ютері.

### Крок 2. Встановіть Node.js (якщо ще не встановлено)
Переконайтеся, що на вашому ПК встановлена платформа Node.js:
1. Завантажте та встановіть її з офіційного сайту: [https://nodejs.org/](https://nodejs.org/) (рекомендується версія LTS).

### Крок 3. Встановіть залежності
1. Відкрийте термінал (або Командний рядок / PowerShell на Windows) у папці з розпакованим проектом.
2. Виконайте наступну команду для встановлення всіх необхідних пакетів:
   ```bash
   npm install
   ```

### Крок 4. Запустіть додаток
Виконайте команду у терміналі для старту локального сервера:
   ```bash
   npm run dev
   ```

### Крок 5. Відкрийте у браузері
Після запуску відкрийте ваш улюблений браузер та перейдіть за адресою:
👉 **[http://localhost:3000](http://localhost:3000)**

## 🛠️ Доступні скрипти для розробки

У папці проекту ви можете виконувати такі команди:
* `npm run dev` — Запуск локального сервера розробки з авто-оновленням (працює на порту 3000).
* `npm run build` — Компіляція оптимізованої версії додатку для продакшну.
* `npm run start` — Запуск скомпілованої стабільної версії проекту.
* `npm run lint` — Швидка перевірка коду на наявність помилок та відповідність типам TypeScript.

## ☁️ Деплой на сервер і подальші оновлення (через Git)

Якщо система розгортається не на локальному ПК, а на VPS-сервері, найзручніший спосіб оновлювати її — через Git. Так кожне оновлення коду зводиться до однієї команди замість ручного перезаливання файлів.

### Перший деплой (один раз)

1. **Створіть приватний репозиторій** на GitHub або GitLab і залийте туди код проєкту:
   ```bash
   git remote add origin <URL_вашого_репозиторію>
   git branch -M main
   git push -u origin main
   ```
2. **На сервері** клонуйте репозиторій, встановіть Node.js (LTS), і створіть файл `.env` на основі `.env.example` — обов'язково задайте `APP_PASSWORD`, якщо сервер буде доступний ззовні:
   ```bash
   git clone <URL_вашого_репозиторію> game-crm
   cd game-crm
   cp .env.example .env   # відредагуйте APP_PASSWORD, PORT, HOST
   npm install
   npm run build
   ```
3. **Встановіть PM2** (менеджер процесів — тримає сервер запущеним і автоматично перезапускає при падінні чи перезавантаженні сервера):
   ```bash
   npm install -g pm2
   pm2 start ecosystem.config.cjs
   pm2 save          # щоб PM2 підняв застосунок після перезавантаження сервера
   pm2 startup       # виконайте команду, яку виведе ця команда, щоб PM2 стартував разом з ОС
   ```

### Кожне наступне оновлення

Коли з'являються зміни в коді (нова функціональність, виправлення), на сервері достатньо одного скрипта:
```bash
./deploy.sh
```
Він сам виконує `git pull`, `npm install`, `npm run build` і `pm2 restart game-crm`. Простій — кілька секунд, дані у `data/db.json` при цьому не чіпаються.

Перевірити стан і логи запущеного застосунку:
```bash
pm2 status          # чи запущено, скільки пам'яті займає
pm2 logs game-crm   # живі логи сервера
```
