# Project Guidelines & Rules

## 1. Full-Screen / Full-Width Layout
- Always render layouts, header banners, tab bars, main content areas, cards, and data tables across the **full screen width** (`w-full` with responsive container padding like `px-4 sm:px-6 lg:px-8`).
- Never artificially constrain views inside narrow or cramped containers (e.g. avoid `max-w-7xl mx-auto` or `max-w-5xl` for top-level pages and headers).

## 2. Minimalist, Direct Headers and Buttons
- Module headings must be short, clean, and direct without verbose subheadings, marketing slogans, or lengthy descriptions:
  - **Завдання** (Button: `+ Нове завдання`)
  - **Фінанси** (Buttons: `Звіти`, `+ Нова операція`)
  - **Постачальники** (Button: `+ Новий постачальник`)
  - **Огляд**
  - **AI Помічник**
- Avoid adding redundant parenthetical qualifiers or multi-sentence descriptive subtitles under page titles and cards.
